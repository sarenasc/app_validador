Validador de Etiquetas

Conexión a SQL Server

Es la primera vez que se abre el sistema. Ingresa los datos del servidor SQL Server: se creará la base de datos (si no existe) y todas sus tablas. Esto se hace una sola vez.

Solo si la app corre en Windows (no en Docker).

Acércate hasta que la etiqueta llene la pantalla (mejor con el teléfono horizontal), toca la etiqueta para enfocar y espera que se vea nítida, con buena luz y sin reflejos. Si algún dato no se lee, agrega otra foto de la misma etiqueta (puedes elegir varias en Galería): se completa con lo que se lea en cualquiera. También puedes escribir los datos abajo y presionar Validar.
